# Pets in Tabs

Pets in Tabs는 웹페이지 위에서 움직이는 픽셀 펫을 보여 주는 Chrome 확장 프로그램입니다. 2.0에서는 기존 펫 9종을 무료로 이용할 수 있습니다. 추가 펫인 민트여우는 미화 $0.99 단건 구매 상품으로 준비 중입니다.

- [Chrome 웹 스토어](https://chromewebstore.google.com/detail/pets-in-tabs/hgbjkkcokknhcfbdkbpkkjmkpnecdbmh)
- [구매 및 복원 안내](payment.html)

## English

Pets in Tabs is a Chrome extension that brings animated pixel pets to web pages. Version 2.0 includes nine free classic pets. The optional Mint Fox is planned as a one-time US$0.99 purchase.

- [Chrome Web Store](https://chromewebstore.google.com/detail/pets-in-tabs/hgbjkkcokknhcfbdkbpkkjmkpnecdbmh?hl=en)
